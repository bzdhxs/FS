# 光谱融合数据集构建报告

## 构建参数

| 参数 | 值 |
|------|-----|
| SG 滤波 | window=11, polyorder=2 |
| 变换类型 | Raw / SNV / FOD / CR |
| Step1 分位数阈值 | Q(0.7) — 保留前 30% |
| Step2 冗余阈值 | 特征间 Pearson \|r\| > 0.95 则去除 |
| 融合后总特征数 | 47 |
| 筛选依据 | 训练集 Pearson \|r\|（测试集完全隔离）|
| 训练集输出 | `fusion_train.csv` |
| 测试集输出 | `fusion_test.csv` |
